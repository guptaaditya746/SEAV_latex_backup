\chapter{Conclusion and Future Directions}
\section*{Conclusion}
In this project, we built a software framework for an autonomous vehicle using low-cost hardware and ROS 2. We connected essential sensors like a LiDAR, an IMU, and color sensors to the system. We also set up a manual control interface with a keyboard and joystick. This helped us test basic functions such as static mapping and localization.

Our tests showed that the system can create static maps and support some dynamic or global localization. We were able to verify core functionality and ensure system stability despite hardware limits. The manual control interface proved useful in validating our design and testing the communication between components.

We did not achieve full sensor fusionin this project. Real-time sensor calibration remains pending, and the system still depends on manual control. These limitations were mainly due to hardware constraints and challenges in managing communication delays among the sensors and controllers.

Throughout development, we gained hands-on experience with ROS 2 node setup, TF tree configuration, and data synchronization across multiple sensor streams. We also learned a lot about integrating different types of sensors and handling the practical limits of devices like the Arduino and Raspberry Pi. This process improved our understanding of how to bring together diverse hardware and software components in a robotics system.

Looking ahead, this project can be added with sensor fusion using methods like the Extended Kalman Filter, improve SLAM performance in dynamic environments, and work toward autonomous navigation with collision avoidance. This project lays a solid foundation for future work on developing a more robust autonomous vehicle system, and it provides valuable lessons for further research and practical applications.


\section*{Future Directions}

To enhance the capabilities of the developed robot, the following improvements are proposed. These are categorized based on implementation complexity and priority.

\subsection*{1. Easy / High Priority Enhancements}
\begin{itemize}
    \item Integrate a camera for live video feed and remote monitoring.
    \item Add object detection using pretrained neural networks (e.g., MobileNet, YOLO).
    \item Mount ultrasonic sensors at each corner for blind spot detection.
    \item Improve TF tree by refining static transforms and buffering.
    \item Integrate magnetenometer for steering feedback and also before it check do calibration.
    \item Developing package for Calibration of all sensors
\end{itemize}

\subsection*{2. Mid-Level Enhancements}
\begin{itemize}
    \item Implement a ROS~2-compatible tricycle joint controller for realistic drive behavior.
    \item Add wheel encoders to enhance odometry accuracy.
    \item Incorporate real-time obstacle avoidance using costmaps and local planner adjustments.
    \item Build a real-time monitoring dashboard for sensor and robot state feedback.
\end{itemize}

\subsection*{3. Advanced  Extensions}
\begin{itemize}
    \item Fuse camera, Lidar, and IMU data for robust 3D SLAM.
    \item Experiment with deep learning-based perception and control methods.
    \item Add autonomous goal selection and task-level decision-making modules.
    \item Extend to multi-robot systems with inter-robot coordination.
    \item Optimize deployment for edge devices like NVIDIA Jetson or Google Coral.
\end{itemize}
